# 知识点网站

纯静态、零数据库、零后台的知识点学习站。免费托管在 GitHub Pages，手机夸克浏览器直接打开。

## 文件结构

```
知识点网站/
├── index.html        # 页面骨架（勿动）
├── style.css         # 样式（勿动）
├── app.js            # 逻辑（勿动）
├── data.js           # ★ 知识点数据（加内容只改这个文件）
└── assets/
    ├── audio/        # 听写音频 mp3（命名规则：编号-N.mp3，如 语003-1.mp3）
    └── images/       # 图片（作文原图等，预留）
```

## 怎么加知识点（只改 data.js）

打开 `data.js`，在对应学习者的 `items` 里按已有格式追加一条：

```js
{
  subject: "语文",              // 科目（树的第一层）
  chapter: "古诗默写",           // 章节（树的第二层）
  no: "语010",                  // 编号（库内唯一，勿重复）
  kp: "古诗默写·示例",           // 知识点标签（卡片标题）
  q: "问题内容（可换行 \n）",
  a: "答案内容（可换行，支持【口诀】【举例】分段）",
  date: "2026-09-17"            // 添加日期（当天的会进"今日复习"新学额度）
}
```

**加听写练习**（可选）：给条目加 `pinyin` 字段，词与词之间用**全角空格**分隔；每个词配一个音频文件放 `assets/audio/`，命名为 `编号-N.mp3`（N 从 1 开始按顺序）。例：语003 有 8 个词 → `语003-1.mp3` ~ `语003-8.mp3`。

**加图片**（可选，作文类）：图片放 `assets/images/`，条目加 `qimg: "assets/images/xxx.png"`（原文图）、`aimg: "..."`（批改图）。带 qimg 的条目不参与复习排期。

改完保存、刷新网页即生效，**零构建**。

## 本地预览

在本文件夹运行 `python3 -m http.server 8080`，浏览器打开 `http://localhost:8080`。（直接双击 index.html 也能看，但音频需服务器方式才稳定。）

## 部署到 GitHub Pages（拿到永久网址）

本站点**同一份代码部署到两个 GitHub 账号**，得到两个网址；**默认库按访问域名自动匹配**，不需要改任何配置：

| 账号用户名里含 | 网址 | 打开后默认是 |
|---|---|---|
| `yyx` | `https://你的yyx用户名.github.io` | 杨研行库 |
| `yzx` | `https://你的yzx用户名.github.io` | 杨知行库（现有 9 条，含听写音频） |

每个账号各做一遍下面 4 步：

1. 登录 [github.com](https://github.com)（免费）。**用户名 = 未来网址**那一段。
2. 点右上角 **+** → **New repository**，仓库名**必须**填 `你的用户名.github.io`（和用户名完全一致 + `.github.io`），选 **Public**，勾上 `Add a README file`，点 Create repository。
3. 进仓库后点 **Add file → Upload files**，把本文件夹解压出来的 `index.html`、`style.css`、`app.js`、`data.js` 和 `assets` 文件夹（保持里面 `audio/` 结构不变）**一起拖进去**，拉到底点 **Commit changes**。
4. 等 1~2 分钟，访问 `https://你的用户名.github.io`。手机夸克打开同一网址，可"添加到主屏幕"当 App 用。

> 若 2 分钟后打不开：进仓库 **Settings → Pages**，确认 Source 是 `main` 分支 / `/(root)`，再等一会儿。

以后更新内容：改好 `data.js` 后，在仓库里点该文件 → 铅笔图标编辑粘贴新内容 → Commit，网址自动更新（约 1 分钟）。

## 学习进度

- 进度存在**本机浏览器**（localStorage），分库隔离，无任何云端依赖。
- **换手机**：站内「自由学习」底部 → 「导出进度」存一份 json → 新手机打开网站 → 「导入进度」。
- 机制：每日复习 5 条；累计答对 5 次=已掌握；答错当天强制重练到对；间隔按 1/2/4/7/15 天艾宾浩斯拉长；连续打卡激励。

## 转交

- **只给内容**：直接把网址给对方。
- **整体移交**：把本文件夹打包给对方（照上面步骤可重新部署），或转让 GitHub 仓库权限。

- **杨研行**：预留空库，补内容后自动出现在切换列表
